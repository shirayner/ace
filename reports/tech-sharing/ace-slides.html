五层 Harness 体系

┌─── Layer 5: Skills ─── Guides ─── 认知协议

├─── Layer 4: Rules ──── Guides ─── 行为标准

├─── Layer 3: Memory ─── Guides ─── 知识持久化

├─── Layer 2: Hooks ──── Sensors ── 自动化检查

└─── Layer 1: Hookify ── Sensors ── 危险拦截

底部确定性（100%）→ 顶部概率性（~95%）| 每层独立可选

架构全景。从底部 Sensors 到顶部 Guides，每层解决一个具体问题。时间：2分钟。

auto-goal 核心设计

三条硬规则

1. 首轮对齐不可跳过

分析 → 澄清 → 确认

2. Surprise Test

用户会惊讶？→ 暂停询问

3. 长任务状态外化

Tier 1 索引 + Tier 2 按需

五条生成式原则

1. 先定义完成，再开始执行

2. 承诺计划，卡住换方向

3. 永不空手而归

4. 上下文是稀缺资源

5. 对齐不是一次性事件

注意：auto-goal 没有 OODA 循环，那是 coding skill 的。auto-goal 的核心是对齐协议和状态外化。时间：2分钟。
