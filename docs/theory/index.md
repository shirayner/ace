## Claude Code 设计哲学

### 核心设计原则

Claude Code 的设计体现了 Anthropic 对 AI 辅助编程的深层理解：

#### 1. 渐进披露 (Progressive Disclosure)

信息不是一次性全部呈现，而是根据上下文按需加载：

```
触发层 (Description)    → 100 词，始终在上下文
认知层 (SKILL.md body)  → 500 行，触发时加载
资源层 (References)     → 不限，按需加载
```

#### 2. 工具使用即思考

每个工具调用都是推理过程的外显：

```
思考 → 选择工具 → 执行 → 观察 → 更新思考
```

这与 ReAct (Reasoning + Acting) 框架一致。

#### 3. 上下文稀缺性

上下文窗口是工作记忆，必须主动管理：

| 策略 | 做法 |
|------|------|
| 压缩 | 已完成阶段摘要化 |
| 外化 | 关键决策写入文件 |
| 隔离 | 探索工作放 sub-agent |

## OpenAI Agent 设计哲学

OpenAI 在《Practical Guide to Building Agents》中提出的核心原则：

### 1. 简单开始，按需增加复杂度

```
简单任务 → 直接执行
复杂任务 → 规划 → 执行 → 验证
```

### 2. 工具设计决定上限

好的工具应该：
- 职责单一
- 输出自解释
- 错误信息清晰

### 3. 可观测性优先

Agent 的每一步都应该可检查、可调试。

## 核心设计原则总结

综合所有理论，ACE 提炼出以下核心原则：

1. **验证内建** — 每步操作自带验证闭环
2. **认知经济** — 主动管理上下文，足够好就前进
3. **双速切换** — 正常流畅执行，异常时切慢速分析
4. **信念持续更新** — 每步反馈都更新对任务的理解
5. **渐进式分解** — 先粗后细，按需展开
6. **策略多样性** — 丰富的策略库 + 有序升级链
7. **外化记忆** — 将状态外化到文件，扩展工作记忆

这些原则相互支撑，形成完整的认知增强系统。
