# 认知科学基础

探索 ACE 设计的认知科学根基

## 1. 元认知 (Metacognition)

### 1.1 什么是元认知

**元认知**是"关于认知的认知"，包含两个核心能力：
- **自我监控** (Monitoring)：实时评估当前策略的有效性
- **自我调节** (Regulation)：根据监控结果调整策略

> "人类专家之所以高效，不是因为从不犯错，而是因为能在犯错时迅速觉察并修正策略。"

### 1.2 ACE 应用

#### 域感知路由

ACE 的 auto-goal skill 实现了元认知的**自我监控**：

```
接收任务
    ↓
判断任务所处域
    ├─ Clear → 直接响应
    ├─ Complicated → 探索后响应
    ├─ Complex → 试探-感知-响应
    └─ Chaotic → 先止血再诊断
```

#### 置信度校准

ACE 要求明确标记信息确定性级别：

- **FACT** — 经过验证
- **INFER** — 基于事实的推断（高/中/低置信度）
- **ASSUME** — 未经验证的假设

这就是元认知的**自我评估**。

## 2. 认知负荷理论 (Cognitive Load Theory)

### 2.1 核心理论

**John Sweller** 提出：人类工作记忆一次只能处理 **4-9 个信息块**。

认知负荷分为三类：

| 类型 | 定义 | 管理策略 |
|------|------|---------|
| **内在负荷** | 任务本身的复杂度 | 分解任务 |
| **外在负荷** | 信息呈现方式造成的干扰 | 优化呈现 |
| **生成性负荷** | 构建知识图式的努力 | 鼓励投入 |

### 2.2 ACE 应用

#### 三层信息架构

ACE 采用**渐进披露**策略：

```
触发层 (description): ~100 词 — 始终在上下文
认知层 (SKILL.md): <500 行 — 触发时加载
资源层 (references): 不限 — 按需加载
```

这就是**减少外在负荷**。

#### 分块策略

将复杂信息组织为可管理的块：

```
## 代码质量检查

### 1. 函数质量
- [ ] 职责单一
- [ ] 长度适中

### 2. 命名质量
- [ ] 表达意图
- [ ] 避免歧义
```

## 3. 双过程理论 (Dual Process Theory)

### 3.1 Kahneman 的两套系统

**Daniel Kahneman** 在《Thinking, Fast and Slow》中提出：

| System 1 (快思考) | System 2 (慢思考) |
|------------------|------------------|
| 快速、自动、无意识 | 慢速、努力、有意识 |
| 直觉、模式匹配 | 分析、逻辑推理 |
| 低能耗 | 高能耗 |

### 3.2 ACE 应用

#### 复杂度适配

ACE 实现了双模式架构：

```
简单任务 → 快速路径 (System 1) → 识别即行动
复杂任务 → 慢速路径 (System 2) → 深度分析
```

#### 切换信号

```
升级信号（切换到慢速）：
- 偏离预期
- 验证失败
- 弱信号检测

降级信号（切换回快速）：
- 连续顺利
- 模式匹配成功
```

## 4. Flow 理论 (心流)

### 4.1 心流状态

**Mihaly Csikszentmihalyi** 提出心流概念：

一种完全沉浸在某项活动中的心理状态。

### 4.2 心流的条件

| 条件 | ACE 映射 |
|------|---------|
| 明确目标 | 清晰的目标定义 |
| 即时反馈 | 验证内建 |
| 挑战-技能平衡 | 复杂度适配 |
| 深度沉浸 | 上下文保护 |

### 4.3 ACE 应用

```
焦虑区 ←─────────────────→ 无聊区
        ↑                    ↑
   挑战过高              技能过高
        │                    │
        └────── 心流通道 ────┘
              (Challenge = Skill)
```

ACE 通过**复杂度适配**保持开发者在心流通道中。

## 5. 延展心灵 (Extended Mind)

### 5.1 核心理论

**Clark & Chalmers** (1998) 提出**延展心灵**假说：

> "认知过程不仅发生在头脑中，还延伸到外部工具和环境中。"

### 5.2 认知制品 (Cognitive Artifacts)

- **笔记本** — 外部记忆
- **计算器** — 外部计算
- **清单** — 外部监控

### 5.3 ACE 应用

#### 状态外化

```
.tasks/auto-goal-{id}/
├── state.md         # 外化的工作记忆
├── decisions.md     # 外化的决策记录
└── reflections.md   # 外化的反思
```

将认知状态写入文件，**扩展工作记忆**。

#### 记忆系统

```
~/.claude/memory/
├── MEMORY.md          # 记忆索引
├── user_profile.md    # 开发者画像
└── projects/          # 项目记忆
```

跨会话持久化认知状态。

#### 环境即记忆

代码库、配置文件本身就是分布式认知系统的一部分。ACE 强调从环境中读取已有认知，而非从零推断。

## 6. 情境认知 (Situated Cognition)

### 6.1 核心理论

**Lave & Wenger** 提出：

> "认知不是脱离环境的抽象过程，而是嵌入具体情境中的活动。"

### 6.2 行动中的理解

理解产生于与环境的交互，而非先于交互。

### 6.3 ACE 应用

#### 试探 (Probe) 策略

在 Complex 域中：

```
设计小实验 → 执行 → 观察涌现 → 提取模式
```

通过行动获取环境反馈，逐步建立理解。

#### 假设驱动行动

```
每个变更是一个假设：
"修改 X 应该产生效果 Y"

实际结果 vs 预期 → 更新理解
```
