# ✅ 预期行为检查清单

**在生成报告前，请自检以下项目。如果不满足，返回相应步骤重新执行**：

---

## Step 3 自检 - 角色选择

- [ ] 是否从 `resources/roles.json` 读取并显示了可用角色列表？
- [ ] 是否让用户明确选择了一个角色（编号或 ID）？
- [ ] 是否成功加载了选定角色的 `standard.md` 和 `template.md`？
- [ ] 是否向用户确认了"模板结构已加载"？

---

## Step 4 自检 - 敏捷拆分

- [ ] 是否识别了 PRD 中的 Epic 层级？
- [ ] 是否识别了每个 Epic 下的 Feature？
- [ ] 是否识别了关键的非功能需求 (NFR)？
- [ ] 是否标注了关键风险或约束？

---

## Step 5 自检 - 多轮对话评审

- [ ] 是否基于角色的 `standard.md` 进行了评审？
- [ ] 是否识别了具体的问题/风险（可分配 P0/P1 优先级）？
- [ ] 是否识别了推断项（AI 自动推断但需确认）？
- [ ] 是否识别了假设项（因信息缺失而引入的假设）？
- [ ] 是否允许用户输入 `done` 结束对话？

---

## Step 6-7 自检 - 报告生成

- [ ] 是否解析了选定角色的模板结构？
- [ ] 是否从工作流输出中提取了与模板相关的内容？
- [ ] 是否使用了动态映射规则（而非硬编码映射）？
- [ ] **报告结构是否遵循模板的原始结构**？
  - 模板包含什么字段，报告就填充什么字段
  - 模板没有的字段，不要添加到报告中
- [ ] 是否填充了模板中所有已定义的必需字段？
- [ ] 是否在问题清单表格中标注了优先级（P0/P1）？
- [ ] 是否在推断/假设缺口中明确标注了推断项和假设项？
- [ ] 是否保持了模板的原始格式和风格（包括 emoji、表格格式等）？

---

## Step 8 自检 - 保存输出

- [ ] 是否根据工作流类型选择了正确的文件名？
- [ ] 是否保存到正确的目录 `~/.prd-review/{PRD_TITLE}/`？
- [ ] 是否向用户显示了完整的文件路径和报告摘要？
