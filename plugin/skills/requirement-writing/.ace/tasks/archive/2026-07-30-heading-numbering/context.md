# PRD 章节标题层级序号

## 目标
让最终生成的 PRD 章节标题带有序层级序号(1. / 1.1 / 1.1.1)。

## 已对齐决策(用户)
- 加序号规则
- 默认带(每份 PRD 都带)
- 只编章节标题 ## / ###;REQ-001/BR-001/AC-001 语义编号保持不变

## agent 设计决策
- 归 Structure 象限,规则落 chapter-tree.md(章节如何组织)
- 模板 core.md 等的 `##` 裸标题不写死序号——因章节是动态选章的,序号须在全篇组装后按最终出现顺序派生,写死进单章模板会与选章冲突

## 完成标准
- chapter-tree.md 有清晰规则:序号层级、默认带、范围只到标题、派生自最终顺序
- 与 prd-language 编号规范(REQ/BR/AC)不冲突,显式说明两者关系
- 模板不动,无死引用
