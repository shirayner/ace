## 估算公式模板

### QPS 估算

```
日活用户 (DAU) = ?
每用户日均操作数 = ?
日总请求量 = DAU × 操作数

平均 QPS = 日总请求量 ÷ 86,400
峰值 QPS = 平均 QPS × 峰谷比（通常 2-5x，秒杀可达 10-100x）

写 QPS = 总 QPS × 写比例
读 QPS = 总 QPS × 读比例
```

### 存储估算

```
单条记录大小 = ? KB
日新增记录数 = ?
日增存储 = 记录大小 × 日新增数

年存储 = 日增存储 × 365
保留策略：N 年数据 = 年存储 × N

加冗余（副本/索引）：实际存储 = 原始 × 3-5x
```

### 带宽估算

```
入带宽 = 请求大小 × 写 QPS
出带宽 = 响应大小 × 读 QPS

加峰值：峰值带宽 = 平均 × 峰谷比
```

### 机器数估算

```
单机处理能力 = X QPS（基于压测或经验值）
所需机器数 = 峰值 QPS ÷ 单机能力 × 冗余系数（通常 1.5-2x）
```

## AI/LLM 系统额外估算

### Token 成本估算

```
每请求输入 Token ≈ ?（prompt + context）
每请求输出 Token ≈ ?
单次请求成本 = 输入Token × 输入价格 + 输出Token × 输出价格

日成本 = 日请求量 × 单次成本
月成本 = 日成本 × 30

峰值并发 = 峰值 QPS × 平均响应时间(秒)
```

### 上下文窗口估算

```
系统 Prompt Token 数 ≈ ?
用户历史对话 Token 数 ≈ 轮数 × 每轮平均 Token
RAG 召回内容 Token 数 ≈ Top-K × 每段平均 Token

总 Context = 系统 + 历史 + RAG + 当前输入
是否超窗口？需要压缩/截断？
```

### Agent 步数估算

```
平均工具调用次数/任务 = ?
每次工具调用延迟 = ?
总任务延迟 ≈ 调用次数 × (模型推理时间 + 工具执行时间)

循环上限设置 = 预期步数 × 2（防无限循环）
每任务总 Token = 步数 × 每步 Token
每任务总成本 = 步数 × 每步成本
```

## 瓶颈识别

估算完成后，回答这个问题：

> **"什么最先杀死这个系统？"**

| 瓶颈类型 | 信号 | 典型解法 |
|----------|------|----------|
| 读瓶颈 | 读 QPS >> 单库能力 | 缓存、读副本、CQRS |
| 写瓶颈 | 写 QPS >> 单库能力 | 分库分表、异步批量 |
| 存储瓶颈 | 数据量 >> 单机容量 | 分片、冷热分离、归档 |
| 带宽瓶颈 | 响应大/请求密 | CDN、压缩、分页 |
| 计算瓶颈 | CPU 密集运算 | 预计算、分布式计算 |
| GPU 瓶颈 | 推理并发受限 | 批处理、模型路由、缓存 |
| 成本瓶颈 | Token/API 费用失控 | 缓存、小模型路由、限流 |
| 人工瓶颈 | 审核队列堆积 | 自动化分级、优先级队列 |

## 估算心态

1. **数量级正确就够** — 不需要精确计算，10x 差异才有意义
2. **宁可高估** — 低估导致事故，高估最多浪费预算
3. **先估后验** — 估算是起点，上线后用实际数据修正
4. **关注增长** — 当前够用不代表半年后够用
5. **瓶颈单一** — 通常只有一个瓶颈是真正的约束，先解决它
