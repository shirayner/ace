# 上下文纪律

保护和管理有限上下文窗口的四策略。

---

## 策略矩阵

| 策略 | 时机 | 方法 |
|------|------|------|
| **隔离** | 探索性工作（搜索/读大文件/查资料） | 委托给 sub-agent，只回传结论 |
| **压缩** | 大阶段完成后 | 只保留决策和结论，丢弃过程细节 |
| **外化** | 重要发现/决策出现时 | 写入状态文件或 experience.md |
| **预算感知** | 对话持续较长时 | 主动压缩或外化，不等溢出 |

---

## 隔离原则

### 何时用 sub-agent
- 不确定要找什么（开放式搜索）
- 需要跨多文件搜索（>5 个文件）
- 结果量大（会污染主上下文）
- 独立分析维度（并行探索）

### 何时直接操作
- 精确知道文件和位置
- 单文件 Read + Grep
- 搜索一个已知符号

### sub-agent prompt 原则
告诉 sub-agent **你需要什么结论**，不规定搜索步骤。

---

## 压缩规则

压缩时**必须保留**：
- 当前目标和完成标准
- 关键决策及理由
- 已修改文件列表
- 未完成待办
- 验证结果

**可丢弃**：搜索过程、代码分析细节、已完成阶段的中间步骤。

---

## 外化时机

- 重要的技术发现 → state.md 或 experience.md
- 方案决策（含被否方案）→ state.md Decisions 段
- 大量代码分析结论 → 提炼为要点写入文件
- 跨会话需要的信息 → 状态文件
