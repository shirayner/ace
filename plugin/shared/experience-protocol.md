# 经验进化协议

任务完成后提取可复用经验的统一流程。适用于所有工作流（auto-goal / aspec / 直接执行）。

---

## 文件位置（单一规则）

```
IF 项目存在 openspec/ 目录
THEN → openspec/experience.md

ELSE
THEN → .tasks/experience.md
```

⚠️ 经验属于**项目**，不属于工作流或单次变更。无论通过哪个 skill 触发，写入同一个文件。

---

## 触发判断

满足任一 → 执行经验提取：
- 执行中遇到意外、踩坑、策略转换
- 发现反直觉的技术事实
- 找到跨任务可复用的模式

**全部不满足** → 跳过提取，但必须一行式告知用户：`📝 经验检查：本次无新发现`。不要为仪式感编造经验。

---

## 执行流程

### 1. 提取

统一格式（追加到文件末尾）：

```markdown
### E{N}: {场景标题}
- **场景**：{触发情境}
- **发现**：{具体经验}
- **适用范围**：{何时可复用}
- **验证记录**：{首次记录(日期)/待验证}
```

提取要求：
- 编号 E{N} 递增，不重复
- 一条经验只记录一件事（原子性）
- "发现"必须是具体可操作的知识，不是泛泛感受

### 2. 应用

新任务启动时读取 experience.md（如存在）：
- 应用时告知用户："基于经验 E{N}，采用…"
- 每次应用后记录验证结果：在对应条目 `验证记录` 追加 `✓有效 / ✗无效 / —不适用`

### 3. 收敛

- 条目 >20 → 合并相似、淘汰无效（需用户确认）
- 累计 3+ 次 ✓有效 → 调用 AskUserQuestion 提议提升至 `~/.claude/memory/`
- ✗无效 累计 2+ 次 → 标记为 `[DEPRECATED]` 并建议删除

---

## 告知用户（必须执行）

无论是否有新经验，任务完成时一行式告知：

- 有经验：`📝 经验提取：E{N} 已写入（简述发现）`
- 无经验：`📝 经验检查：本次无新发现`
