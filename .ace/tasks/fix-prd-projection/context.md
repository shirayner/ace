# 修复 PRD 投影一致性

## 目标
修复需求规模从理解阶段到撰写阶段发生漂移，以及结构化业务流程漏生成流程图的问题。

## 输入
- 飞书需求文档：https://trip.larkenterprise.com/docx/Wi9Gd1R72oaD8mx9NdqcQj2dnpd
- 用户实测：理解阶段判定 Normal，PRD 文档信息写成 Large；含过滤、判断、聚合和跳转的流程未生成图。

## 完成标准
- 使用 feishu2md 读取原文并建立失败基线。
- 规模仅忠实投影上游 Micro / Normal 结论。
- 有结构的流程必须生成语义一致的 Mermaid 图。
- 同案例端到端回归和静态检查通过。

## 过程记录

### 决策
- **D1**：修复规则并做案例端到端回归，不重写完整 PRD。
- **D2**：分支、过滤、循环、并行、回流、跨角色/系统交接或多阶段跳转出现时必须画图；只有简单线性短流程可豁免。

### 风险
- 规则可能散落于 SKILL、投影规则、模板和审查约束中，需检查整条语义链而非局部补丁。
