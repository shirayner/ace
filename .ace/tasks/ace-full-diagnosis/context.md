# ACE Full Diagnosis — Context

## 目标
对 ACE 项目做全面诊断，识别功能缺口、确定扩展方向，为 Roadmap 提供决策输入。

## 关键决策
- 分析范围：全面诊断（功能缺口 + 产品定位 + 架构演进 + 生态建设）
- 目标边界：软件交付全生命周期 + 开发者日常 + AI+人协作 + 团队级工程化
- 多角色 skill（运营/产品/视觉/交互）状态：规划中，尚未开始

## 核心发现
1. ACE 的真正护城河是认知协议层（对齐/验证/经验积累）
2. 当前"开发深井"现象：编码 85%，部署 10%，运维 5%
3. 最高 ROI 方向：debug-assistant, refactor, integration-test
4. 架构第一步：MCP Server 化
5. 生态第一步：Skill IR 规范 + Git-based 知识同步
